# AI 行动选项更新仓库

这里存放 SillyTavern 酒馆助手脚本“AI 行动选项”的可安装构建、更新清单和对应源码。

## 当前发布状态

当前仅发布 `1.6.2` 的测试序列，**不是正式版**。测试构建用于验证更新检查、端点切换、安装和回退流程；确认稳定后会另行发布正式版 `v1.6.2`。

每个版本均通过独立 Git 标签隔离，标签内同时保存：

- `index.js`：该版本的可安装构建
- `src/AI行动选项/`：与构建对应的源码快照
- `manifest.json`：发布时的更新清单快照

更新器从 `main/manifest.json` 读取当前版本列表，再通过不可变版本标签下载对应构建并校验 SHA-256。

## 测试渠道

| 版本 | 用途 |
| --- | --- |
| `1.6.2-testing.3` | 增加禁用态“剧情时间线”预览入口，用于确认版本已切换 |
| `1.6.2-testing.2` | 仅增加测试版本号，用于验证纯版本更新与回退 |
| `1.6.2-testing.1` | 相对 1.6.1 的完整功能测试基线 |

正式版 `1.6.2` 的语义化版本优先级高于全部 `1.6.2-testing.*`，测试用户后续可以正常升级。

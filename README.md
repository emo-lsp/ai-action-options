# AI 行动选项

为 SillyTavern 对话生成贴合当前剧情的行动选项，让每一轮回复都有可继续推进的方向。

**当前版本：1.6.3 · 作者：emo的lsp**

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动生成 | AI 回复完成后生成行动选项，也可手动重新生成 |
| 行动模板 | 选择内置模板或配置自定义模板 |
| 剧情上下文 | 结合最近回复、角色资料与勾选的世界书条目 |
| 历史摘要 | 读取较早剧情摘要，支持自动识别、自定义标签和逐楼层预览 |
| 外接模型 | 支持 DeepSeek 与自定义兼容接口 |
| 更新中心 | 自动检查、红点提醒、版本说明、端点选择和手动安装 |

## 使用前准备

- 已安装并启用 Tavern Helper（酒馆助手）的 SillyTavern。
- 可用的模型 API、API Key 和模型名称。
- 能访问至少一个脚本下载端点的网络环境。

建议作为全局脚本长期启用，同一功能只启用一份，避免重复生成。

## 安装

1. 打开酒馆助手的脚本管理，新建一个全局脚本。
2. 将名称设为“AI 行动选项”，在“脚本内容”中填写：

```js
import 'https://testingcf.jsdelivr.net/gh/emo-lsp/ai-action-options@v1.6.3/index.js';
```

3. 保存并启用脚本，打开脚本设置完成模型配置。

备用安装地址，选择其中一个即可：

**jsDelivr**

```js
import 'https://cdn.jsdelivr.net/gh/emo-lsp/ai-action-options@v1.6.3/index.js';
```

**GitHub Raw**

```js
import 'https://raw.githubusercontent.com/emo-lsp/ai-action-options/v1.6.3/index.js';
```

不同端点的可达性取决于网络环境，部分网络需要代理。

## 首次配置

1. 在“外接 API”中选择服务商，填写 API Key 和模型；自定义接口还需填写 Base URL。
2. 在“生成与模板”中选择行动模板，并按需调整最近回复与历史摘要范围。
3. 在“附加世界书”中检查当前角色的资料条目。
4. 开启自动生成，或使用脚本的手动重新生成按钮。

设置修改后自动保存。更长的上下文通常消耗更多 Token，请按剧情需要配置。

## 检查更新

桌面端在设置左侧打开“更新”；手机端入口位于底栏。

- **自动检查**：最多每 24 小时检查一次，发现更新显示红点，不会自动安装。
- **立即检查**：重新请求版本清单，不等待脚本本地缓存到期。
- **自动选择端点**：比较可用端点的清单，选择最新版本。
- **手动安装**：查看更新内容并确认后，校验下载文件、替换当前脚本并保留设置；完成后提示刷新页面。

安装地址固定初始版本，后续通过更新中心升级，无需手动修改地址中的版本号。

## 常见问题

### 看不到新版本

CDN 清单可能尚未同步。切换到 GitHub Raw 后点击“立即检查”；仅切换下拉选项不会立即替换上一次检查结果。

### 安装后页面没有自动刷新

从较早版本升级时，若安装已完成但界面仍未刷新，可手动刷新页面，再打开设置核对版本号。

### 生成失败或没有行动选项

检查 API Key、Base URL、模型名称及服务余额，确认自动生成已开启。若请求超时，可调整超时时间或减少上下文。

## 隐私与费用

生成请求会将所选剧情上下文和角色资料发送给配置的模型服务商，并可能产生 API 费用。请仅使用可信服务，不要在截图、问题反馈或公开文件中暴露 API Key。

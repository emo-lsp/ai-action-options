# AI 行动选项

SillyTavern 酒馆助手脚本：根据当前剧情生成行动选项，支持自动生成、行动模板、角色资料、历史摘要和外接模型。

## 正式版本

当前版本：**1.6.3**。更新清单和 Release 仅提供此正式版，不再提供测试版本。

## 安装

需要已启用 Tavern Helper（酒馆助手）的 SillyTavern。在酒馆助手中新建全局脚本，将以下内容作为脚本代码并启用：

```js
import 'https://testingcf.jsdelivr.net/gh/emo-lsp/ai-action-options@v1.6.3/index.js';
```

此端点不可达时，可将 `testingcf.jsdelivr.net` 换为 `cdn.jsdelivr.net`，或使用 GitHub Raw：

```js
import 'https://raw.githubusercontent.com/emo-lsp/ai-action-options/v1.6.3/index.js';
```

端点可达性取决于实际网络，不能保证一定无需代理。脚本需要配置自己的外接 API；不要将 API Key 上传到 GitHub。

## 更新

- 桌面端在设置左侧打开“更新”，手机端入口位于底栏。
- 自动检查最多每 24 小时进行一次；发现更新显示红点，不会自动安装。
- “立即检查”绕过脚本本地缓存。自动模式比较各可用端点的清单，选择最新版本；指定端点时仅使用所选端点。
- 查看版本说明后手动确认安装。下载内容通过 SHA-256 校验后才替换当前脚本，保留原设置。
- 安装完成显示顶部通知，随后刷新 SillyTavern 页面。
- 从旧测试版首次升级时，旧安装器可能停留在“正在安装”。若写入后未刷新，手动刷新一次再检查版本。新宿主安装器用于后续安装流程。

## 源码与版本隔离

| 文件 | 用途 |
| --- | --- |
| `index.js` | 生产构建 |
| `src/AI行动选项/` | 对应源码快照 |
| `manifest.json` | 更新列表、下载标签和 SHA-256 |

`v1.6.3` 标签固定源码与构建；后续版本使用新标签，不覆盖旧标签。源码依赖酒馆助手开发 workspace 的公共工具和类型声明，本仓库不是独立构建工程。

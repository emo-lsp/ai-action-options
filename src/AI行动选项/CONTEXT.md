# AI Context

## 项目概述
这是一个 SillyTavern / Tavern Helper 后台脚本，用于让外部模型以 JSON 生成行动选项，并在校验后转换、追加为前端兼容的 `<options>...</options>`。技术栈以 TypeScript + jQuery + Zod 为主，配合外接 DeepSeek / OpenAI 兼容接口、世界书读取和酒馆事件监听。

## 当前状态
更早剧情摘要已接入设置与生成链路，默认关闭，可选正文之前指定层数或全部更早摘要，支持自动识别、自定义标签和逐层预览。当前版本保持为 1.6.2，已在设置页加入多端点版本检查、更新记录、手动安装与新版本红点。本轮按用户要求仅在本地开发，不推送。

脚本已支持自动监听最新 AI 楼层、调用外部模型生成选项、回写楼层，并通过设置弹窗配置模板、模型参数和角色补充资料来源。模型输出协议为严格 JSON `{"options":[...]}`；格式错误时静默重试至多 2 次，生成中与完成弹窗均显示重试次数，成功后仍转换为旧 `<options>` 标记供现有前端渲染。当前补充资料已改为自动跟随当前角色卡，并会在切换角色卡后校验读取结果并弹出成功/失败提醒。设置弹窗版本为 `1.6.2`，固定使用卡库像素风，已删除其他主题、主题按钮和主题偏好读写。主设置页及预览、世界书选择、自定义模板编辑子弹窗保持一致。模板、思考模式与思考强度使用自定义下拉控件，隐藏 select 仅用于原配置读写和 change 保存链路。主体为侧边导航（概览/生成与模板/附加世界书/外接 API/更新）+ 右侧面板；手机端保留原 2×2 主导航，更新入口放在底栏右侧；自动生成和行动模板集中在“生成与模板”页，附加世界书通过独立导航入口在右侧面板显示，角色资料不再单独占用导航页面。设置页已接入短促像素风微交互：页签按方向入场、下拉展开收起、按钮按压、开关/复选框回弹和提示条淡入淡出；仅使用 transform/opacity，支持 `prefers-reduced-motion` 并在弹窗关闭时清理。设置字段采用防抖即时保存，关闭弹窗前会再同步一次正式设置；旧版本遗留草稿只在首次打开时迁移。子弹窗直接显示最终尺寸，不使用酒馆原生缩放动画。设置弹窗、生成进度和完成/错误通知均使用卡库暖纸像素风；生成中的边框流光连续绕行，终态只播放一次边框盖章反馈，减少动态效果模式保持静止；价格估算与缓存统计卡片独立控制，缓存统计受抑制时仍可显示有效价格，价格展示固定保留三位小数并四舍五入；计时刷新频率为 100ms。新配置的温度默认为 0.5、最大输出token 默认为 8192，已有保存值不强制迁移。DeepSeek API 默认使用开启思考 + 低思考强度和 60 秒请求超时，可在弹窗中切换思考模式、思考强度和超时；局部追加后会补发单楼层刷新以兼容新版 JS-Slash-Runner 的代码块渲染。

## 项目结构
context.ts / summary_parser.ts / summary_ui.ts
- 共用正文与摘要读取范围、保守识别成对摘要标签、设置区与只读预览；预览和生成共用提取结果。

character_source.ts
- 当前角色卡来源解析与设置同步，负责自动读取角色世界书或角色描述。

index.ts
- 脚本入口，监听酒馆事件、触发生成、回写楼层、同步当前角色卡补充资料。

custom_select.ts
- 自定义下拉控件、键盘选择与隐藏 select 同步，弹窗关闭时释放事件。

catalog_skin.scss
- 卡库设置皮肤与移动端布局，隔离在 `.tlao-theme-catalog` 下，避免影响宿主和进度弹窗。

popup.ts
- 设置弹窗，展示当前角色卡补充资料状态，并允许调整自动绑定世界书的条目勾选。

update.ts / version.ts
- 固定更新仓库、端点回退、manifest 校验、版本比较、24 小时缓存、SHA-256 校验和当前脚本替换。

custom_presets.ts
- 自定义模板槽位、默认继承关系、固定输出格式拼接与解析后的模板列表。

entry_selection.ts
- 世界书条目默认勾选与手动勾选的统一规则，包含自动取消勾选关键词。

worldbooks.ts / worldbook_reader.ts
- 世界书正文读取与整理。

## 架构与关键决策
- 更新仓库固定为 `emo-lsp/ai-action-options`，不接受任意 URL；自动端点顺序为 testingcf.jsdelivr、cdn.jsdelivr、GitHub Raw。更新只能由用户点击安装，下载内容需与 manifest 中的 SHA-256 一致；替换时依据 `getScriptId()` 定位全局/预设/角色卡范围内的当前脚本，不改动其他脚本。
- “正文窗口”是截至目标楼层最近 N 条有效 AI 回复；“更早摘要”仅来自正文窗口之前。“指定层数”选择之前 M 条 AI 回复，缺摘要时显示缺失，不向更早回填；“全部”随窗口推进追加进入历史区的摘要。用户、明确隐藏和旁白楼层不计入，采用当前 swipe。
- 摘要从原始消息读取；正则仅提供标签线索，不执行任意预设正则或照搬隐藏深度。支持常见 summary/recap/中文标签及摘要 details 折叠；无法识别时允许手动指定单个成对标签名。预览显示来源楼层、标签、正文已包含/将读取/不读取及缺失情况，不生成新摘要。
- DeepSeek 缓存按固定资料、旧到新摘要、最近正文的顺序保留可复用前缀，检测统计不进入稳定前缀；全部模式持续追加，指定窗口会移除最旧摘要。历史编辑、标签或资料变化仍可能改变前缀，实际命中由服务商决定。
- `presets.ts` 只维护内容、视角和槽位规则，不承担 JSON 传输协议；API 适配层会过滤已知旧版 `<options>` 格式行并追加最终 JSON 协议。自定义模板仍只开放“模板名 + 规则正文”编辑，合法 JSON 在写入楼层前转换为 `<options>...</options>`，现有全局正则与远程前端无需修改。
- 自动角色来源直接覆盖 `boundKnowledgeWorldbooks`；不再区分“手动附加世界书”和“自动角色来源”。
- 当前角色卡有世界书时，只读取当前角色卡世界书；切换角色卡后会同步替换旧角色卡内容。
- 当前角色卡没有世界书时，只回退读取 `description`；不会额外引入开场白、示例对话等其他角色字段。
- 切换角色卡后的提醒不是只看“绑定名是否同步成功”，而是会进一步验证世界书条目或角色描述是否真的可用，再决定弹绿色成功还是红色失败提醒。
- 设置弹窗目前不是普通表单堆叠，而是“概览 + 生成与模板 + 附加世界书 + 外接 API”的工具面板布局；左侧只保留导航，附加世界书内容在对应右侧面板呈现。固定采用卡库风格，不再读取或保存主题偏好；旧 localStorage 主题键保留但不使用。移动端主设置外框固定为 `100dvh - 16px`，内容面板内部滚动，子弹窗仍按内容调整高度。
- 思考控制参数只在服务商支持的情况下写入请求：DeepSeek 可发送 `thinking` 与 `reasoning_effort`，自定义兼容接口默认不发送推理参数；请求超时由现有 `timeoutMs` 统一控制。
- DeepSeek 用量捕获只在宿主 `fetch` 可安全赋值时安装临时包装；检测到其他请求监控器托管的 `fetch` 访问器时跳过该包装，避免跨脚本递归，并由成功弹窗隐藏缓存统计、提示用户原因。
- 外部模型请求统一经过 Tavern Helper 后端代理；接口地址按 OpenAI 兼容格式整理为 `/v1`，模型列表和对话生成不再由浏览器直接携带 API Key 访问外站。运行环境需要支持 `getModelList` 与 `generateRaw` 的 Tavern Helper 版本。
- `generateRaw` 的 `custom_api` 未指定采样参数时会使用主预设值；行动选项必须显式设置自身参数或使用 `'unset'`，并始终覆盖 `custom_include_body`、`custom_exclude_body`、`custom_include_headers`，不能依赖主 API 页面配置。
- 成功弹窗只展示能匹配 DeepSeek 模型名的价格估算，并标注请求对应的北京时间价格时段。当前 Tavern Helper 虽只向调用者返回生成文本，但脚本会定向读取本次后端代理响应副本中的 usage；取得 `prompt_cache_hit_tokens` / `prompt_cache_miss_tokens` 后按真实缓存用量计算，捕获失败才回退为本地 tokenizer 和输入全部缓存未命中估算。
- 增量写入楼层后优先调用公开的 `refreshOneMessage` 触发消息渲染事件，不直接伪造酒馆事件；接口不可用或失败时回退到 `setChatMessages(..., { refresh: 'affected' })`。
- 世界书条目如果没有手动保存过勾选结果，则默认使用自动筛掉以下条目名称关键词的勾选集：`[mvu_update]`、`变量更新规则`、`变量列表`、`变量输出格式`、`[initvar]`、`Initvar`、`initvar`、`EJS`、`ejs`、`变量初始化`、`MVU`、`mvu`、`变量`、`分阶段人设`、`分阶段设定`、`多阶段人设`、`多阶段设定`、`角色阶段`、`插图`、`文风`、`选项`、`选开`、`特殊事件`；一旦手动勾选过，就按显式保存结果处理。
